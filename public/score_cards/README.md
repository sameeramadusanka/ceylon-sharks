# Scorecard naming convention

Use this filename format for detailed scorecard JSON files:

`SEASON__MATCH-ID__MATCH-NUMBER__YYYY-MM-DD.json`

Example:

`26_T3_MAY__26_T3_SAT_SUPREME__MATCH-12__2026-09-05.json`

Store scorecards inside a season subfolder, for example `public/score_cards/26_T3_MAY/`.
