# Season statistics naming convention

Use this filename format:

`SEASON__DIVISION__STATISTICS-TYPE__YEAR.json`

Example:

`2026_MAY_SUPREME_DIVISION__2026_MAY_SUPREME_DIVISION__BATTING__2026.json`

Store season-level batting, bowling, and other aggregate statistics in this folder. Match-level details belong in `public/score_cards/`.
Store season-level batting, bowling, and other aggregate statistics inside a season subfolder, for example `public/season_statistics/2026_MAY_SUPREME_DIVISION/`. Match-level details belong in the corresponding `public/score_cards/{season}/` folder.
